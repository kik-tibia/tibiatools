# Contributing

This is a hobby project I maintain on my own, so a few notes before you start.

## Bug reports

These are the most useful things you can send me. Just open an issue and include a build URL if relevant.

## Pull requests

For small fixes (typos, missing weapons or creatures, incorrect constants, etc.), just open a PR.

For anything bigger, please open an issue first. However, be aware that I have my own plans for the site and fairly specific opinions about how it should look and work, so entire new pages, big UI redesigns or wide refactors are probably not going to get merged.

## AI

LLM use is allowed to an extent, but you must have read and understood what you're submitting, and be capable of fully explaining the changes. Full blown vibe coding without reading the output is not welcome. LLMs work best when used as a tool to write better, not faster.
